# 双路特征拼接 v1 实验结果

使用固定划分 v1。训练用 1,400 对，验证用 300 对，测试用 300 对。
水上和水下各从已验证的单路最佳权重出发，冻结特征提取网络和检测头。每个尺度把两路特征拼接，保留固定的本路通道，训练 1×1 投影让搭档特征以残差方式贡献。
训练 10 轮，按两路验证 mAP50–95 的均值选中第 5 轮。

测试时复用相同的输入缩放、NMS、权重和匹配规则。错配对照在同一环境条件的小批次内轮换另一台相机的特征，保留本路和条件标签。
查准率、召回率和找回计数使用置信度 0.25、IoU 0.50。区间是按图像对重采样的 95% bootstrap 区间，细分组结果用于探索。

## 读表结论

按本路成像条件汇总后，尚未有组同时满足相对单路和相对同条件错配的召回增益区间都在零以上。
- 水上总体找回 4 个，丢失 4 个。双路相对单路净变动 +0 个，多报变化 -1 个。
- 水下总体找回 0 个，丢失 5 个。双路相对单路净变动 -5 个，多报变化 +5 个。
- 逐实例核对后，水上找回的 4 个目标在同条件错配时也全部被检对。太阳强反光下找回的 2 个都来自同一对图 `04_dual_hard_300/0236`，搭档水下画面为中度浑浊。另 2 个分别来自水上光照不均和水上理想。当前结果未显示这些找回依赖同一时刻的另一台相机图像。
- 水上 mAP50–95 从 0.778 升至 0.789，但错配时也达到 0.788。这个增量和配对带来的目标找回需要分别解读。
- 结论适用于当前仿真划分和冻结单路网络、训练同位置拼接投影的方案。两机位的视差及跨水面外观差异，在这次模型中没有显式对齐。

具体上下条件组合见 test_results/condition_comparison.csv。逐图结果见 test_results/paired_predictions.jsonl。示例的左、中、右分别为搭档原图、单路预测与双路预测，紫框标注对应的找回或丢失目标。
